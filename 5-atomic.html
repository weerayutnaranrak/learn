Atomic Design

methodology ออกแบบ UI Systems โดย Brad Frost — สร้าง components จากเล็กไปใหญ่ เหมือนนักเคมีสร้างสสารจากอะตอม

💡 Atomic Design คืออะไร?
แนวคิดโดย Brad Frost — "We're not designing pages, we're designing systems of components"

แนวคิดนี้มองว่า Interface เหมือนสสารในธรรมชาติ — ประกอบขึ้นจาก ชิ้นส่วนเล็กๆ (Atoms) ที่รวมกันเป็นสิ่งที่ซับซ้อนขึ้นเรื่อยๆ ทำให้ Design System สอดคล้อง, ซ้ำใช้ได้, และ Maintain ง่าย

⚛️ Atoms — อะตอม

ชิ้นส่วน UI พื้นฐานที่เล็กที่สุด ไม่สามารถแบ่งย่อยได้อีก

Atoms คือ:

• HTML elements พื้นฐาน: button, input, label, image, icon
• Design tokens: สี, font, spacing, border-radius
• ไม่มี context — ใช้ได้ทุกที่
• มีแค่ styling และ basic interaction

ตัวอย่าง Atoms:
Button, Input Field, Label, Badge, Avatar, Icon, Rating Stars, Checkbox

🧬 Molecules — โมเลกุล

กลุ่มของ Atoms ที่ทำงานร่วมกันเพื่อหน้าที่เดียว

Molecules คือ:

• Atoms หลายตัวรวมกันที่มีหน้าที่ชัดเจน
• เช่น: Search Box = Input + Button
• Product Card = Image + Name + Price + Rating + Button
• ยังคง reusable อยู่ในหลายๆ ที่

ตัวอย่าง Molecules:
Search Box, Product Card, Form Field (Label+Input+Error), Stat Card, User Profile Mini, Navigation Link

🦠 Organisms — สิ่งมีชีวิต

Section ที่ซับซ้อน ประกอบจาก Molecules และ Atoms

Organisms คือ:

• Interface sections ที่ standalone และซับซ้อน
• มี business context ชัดเจน
• เช่น: Navbar, Product Grid, Shopping Cart, Footer
• อาจ reuse ได้ แต่ context-specific กว่า Molecules

ตัวอย่าง Organisms:
Navigation Bar, Product Listing Grid, Hero Section, Shopping Cart Sidebar, Footer, Filter Panel, Review Section

📐 Templates — แม่แบบ

Page-level structure ที่แสดง layout โดยยังไม่มีข้อมูลจริง

Templates คือ:

• Wire frame ที่ประกอบ Organisms เข้าด้วยกัน
• แสดง layout structure โดยยังไม่ใส่ real content
• เป็น "skeleton" ของหน้าที่จะแสดงผล
• ใช้ placeholder แทน real data

ตัวอย่าง Templates:
Product Page Template, Homepage Template, Category Page Template, Checkout Template, Dashboard Template

📄 Pages — หน้า

Template + Real Content = สิ่งที่ผู้ใช้เห็นจริงๆ

Pages คือ:

• Template ที่ใส่ real data เข้าไปแล้ว
• สิ่งที่ end-user เห็นจริงๆ
• ทดสอบว่า Design System ทำงานร่วมกับ real content ได้
• เป็น "evidence" ว่า templates ใช้งานได้จริง

สำคัญ:
หน้า Pages ไม่ควรมี styling ใหม่ — ทุก component ใช้จาก levels ที่ผ่านมา

src/components/atoms/AppButton.vue — Atom Vue SFC 
<script setup lang="ts">
type Variant = 'primary' | 'secondary' | 'ghost' | 'danger'
type Size    = 'sm' | 'md' | 'lg'

const props = defineProps<{
  variant?: Variant
  size?:    Size
  disabled?: boolean
  icon?:    string
}>()

const emit = defineEmits<{
  click: [event: MouseEvent]
}>()
</script>

<template>
  <button
    :class="['btn', `btn--${variant ?? 'primary'}`, `btn--${size ?? 'md'}`]"
    :disabled="disabled"
    @click="emit('click', $event)"
  >
    <span v-if="icon" class="btn__icon">{{ icon }}</span>
    <slot />
  </button>
</template>

src/components/molecules/ProductCard.vue — Molecule Vue SFC 
<script setup lang="ts">
import AppButton from '@/components/atoms/AppButton.vue'
import AppBadge  from '@/components/atoms/AppBadge.vue'

export interface Product {
  id:            number
  name:          string
  price:         number
  originalPrice?: number
  discountPct?:  number
  rating:        number
  reviewCount:   number
  primaryImage:  string
  inStock:       boolean
  isNew?:        boolean
}

const props = defineProps<{ product: Product }>()
const emit  = defineEmits<{ 'add-to-cart': [id: number] }>()

const formattedPrice = computed(() =>
  props.product.price.toLocaleString('th-TH')
)
</script>

<template>
  <article class="product-card">
    <RouterLink :to="`/products/${product.id}`" class="product-card__image-link">
      <img :src="product.primaryImage" :alt="product.name" loading="lazy" />
      <AppBadge v-if="product.isNew" color="blue">ใหม่</AppBadge>
      <AppBadge v-if="product.discountPct" color="red">-{{ product.discountPct }}%</AppBadge>
    </RouterLink>

    <div class="product-card__body">
      <h3 class="product-card__name">{{ product.name }}</h3>

      <div class="product-card__rating">
        ⭐ {{ product.rating }} ({{ product.reviewCount }})
      </div>

      <div class="product-card__price">
        <span class="price-current">฿{{ formattedPrice }}</span>
        <span v-if="product.originalPrice" class="price-original">
          ฿{{ product.originalPrice.toLocaleString('th-TH') }}
        </span>
      </div>

      <AppButton v-if="product.inStock" icon="🛒" size="sm"
        @click="emit('add-to-cart', product.id)">
        เพิ่มในตะกร้า
      </AppButton>
      <AppBadge v-else color="red">หมดสต็อก</AppBadge>
    </div>
  </article>
</template>
src/components/organisms/ProductGrid.vue — Organism Vue SFC 
<script setup lang="ts">
import ProductCard, { type Product } from '@/components/molecules/ProductCard.vue'
import { useCartStore } from '@/stores/cart'

const props = defineProps<{
  title:      string
  products:   Product[]
  loading?:   boolean
}>()

const cart        = useCartStore()
const searchQuery = ref('')

const filtered = computed(() =>
  props.products.filter(p =>
    p.name.toLowerCase().includes(searchQuery.value.toLowerCase())
  )
)
</script>

<template>
  <section class="product-grid-section">
    <div class="product-grid__header">
      <h2>{{ title }} ({{ filtered.length }})</h2>
      <input v-model="searchQuery" placeholder="ค้นหาสินค้า..." class="search-input" />
    </div>

    <!-- Loading skeleton -->
    <div v-if="loading" class="product-grid">
      <div v-for="n in 6" :key="n" class="product-card product-card--skeleton" />
    </div>

    <!-- Product list -->
    <div v-else-if="filtered.length" class="product-grid">
      <ProductCard
        v-for="product in filtered"
        :key="product.id"
        :product="product"
        @add-to-cart="cart.add($event)"
      />
    </div>

    <!-- Empty state -->
    <div v-else class="empty-state">
      <span class="empty-state__icon">📭</span>
      <p>ไม่พบสินค้าที่ตรงกับ "{{ searchQuery }}"</p>
    </div>
  </section>
</template>

Vue Project Structure แบบ Atomic: 
src/
├── components/
│   ├── atoms/           ← ชิ้นเล็กสุด  (AppButton, AppBadge, AppInput, AppAvatar)
│   ├── molecules/       ← กลุ่ม atoms  (ProductCard, SearchBox, FormField)
│   └── organisms/       ← sections ใหญ่ (Navbar, ProductGrid, Footer)
├── pages/               ← route-level components (Nuxt: auto-route)
│   ├── index.vue
│   ├── CategoryPage.vue
│   └── ProductDetailPage.vue
├── composables/         ← shared logic  (useCart, useFilters, usePagination)
├── stores/              ← Pinia state   (cart.ts, products.ts)
└── layouts/             ← page shells   (default.vue, minimal.vue)
Props & Emits (data flow)
• Props → ส่งข้อมูลลง (parent → child)
• Emits → ส่ง event ขึ้น (child → parent)
• v-model = props + emit รวมกัน
Composables (logic reuse)
• แทน Mixins ของ Vue 2
• ใช้ use นำหน้าชื่อ (useCart, useAuth)
• return reactive refs ออกมา

atoms/AppButton.spec.ts Atom · Unit Test 
import { mount } from '@vue/test-utils'
import AppButton from '@/components/atoms/AppButton.vue'

describe('AppButton', () => {
  it.each([
    ['primary',   'btn--primary'],
    ['secondary', 'btn--secondary'],
    ['danger',    'btn--danger'],
  ])('variant="%s" adds class "%s"', (variant, expectedClass) => {
    const wrapper = mount(AppButton, { props: { variant } })
    expect(wrapper.classes()).toContain(expectedClass)
  })

  it('renders slot content', () => {
    const wrapper = mount(AppButton, { slots: { default: 'Buy Now' } })
    expect(wrapper.text()).toContain('Buy Now')
  })

  it('renders icon when icon prop is passed', () => {
    const wrapper = mount(AppButton, { props: { icon: '🛒' } })
    expect(wrapper.find('.btn__icon').text()).toBe('🛒')
  })

  it('emits click event when clicked', async () => {
    const wrapper = mount(AppButton)
    await wrapper.trigger('click')
    expect(wrapper.emitted('click')).toHaveLength(1)
  })

  it('does not emit when disabled', async () => {
    const wrapper = mount(AppButton, { props: { disabled: true } })
    await wrapper.trigger('click')
    // disabled attribute blocks native click → no custom emit
    expect(wrapper.emitted('click')).toBeUndefined()
  })

  it('applies correct size class', () => {
    const wrapper = mount(AppButton, { props: { size: 'lg' } })
    expect(wrapper.classes()).toContain('btn--lg')
  })
})

import { mount } from '@vue/test-utils'
import ProductCard from '@/components/molecules/ProductCard.vue'

const baseProduct = {
  id: 1, name: 'Go T-Shirt', price: 299,
  primaryImage: '/img/tshirt.jpg', rating: 4,
  reviewCount: 120, inStock: true, isNew: false,
}

describe('ProductCard', () => {
  it('renders product name and price', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.text()).toContain('Go T-Shirt')
    expect(wrapper.text()).toContain('299')
  })

  it('shows "ใหม่" badge when isNew=true', () => {
    const wrapper = mount(ProductCard, {
      props: { product: { ...baseProduct, isNew: true } },
    })
    expect(wrapper.text()).toContain('ใหม่')
  })

  it('hides "ใหม่" badge when isNew=false', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.text()).not.toContain('ใหม่')
  })

  it('shows add-to-cart button when inStock=true', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.find('button').exists()).toBe(true)
    expect(wrapper.text()).toContain('เพิ่มในตะกร้า')
  })

  it('shows "หมดสต็อก" badge when inStock=false', () => {
    const wrapper = mount(ProductCard, {
      props: { product: { ...baseProduct, inStock: false } },
    })
    expect(wrapper.find('button').exists()).toBe(false)
    expect(wrapper.text()).toContain('หมดสต็อก')
  })

  it('emits add-to-cart with product id when button clicked', async () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    await wrapper.find('button').trigger('click')
    expect(wrapper.emitted('add-to-cart')?.[0]).toEqual([1])
  })

  // Snapshot — เปรียบเทียบ HTML ทั้ง component
  it('matches snapshot', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.html()).toMatchSnapshot()
    // ครั้งแรก: สร้าง __snapshots__/ProductCard.spec.ts.snap
    // เปลี่ยน template: รัน vitest --update-snapshots
  })
})

import { mount }        from '@vue/test-utils'
import { createTestingPinia } from '@pinia/testing'
import ProductGrid from '@/components/organisms/ProductGrid.vue'

const mockProducts = [
  { id: 1, name: 'Item A', price: 100, inStock: true,  rating: 4, reviewCount: 10, primaryImage: '' },
  { id: 2, name: 'Item B', price: 200, inStock: true,  rating: 3, reviewCount: 5,  primaryImage: '' },
  { id: 3, name: 'Item C', price: 300, inStock: false, rating: 5, reviewCount: 20, primaryImage: '' },
]

describe('ProductGrid', () => {
  it('renders correct number of ProductCard components', () => {
    const wrapper = mount(ProductGrid, {
      props:   { title: 'Featured', products: mockProducts },
      global: { plugins: [createTestingPinia()] },
    })
    // ตรวจจำนวน card ที่ render จาก v-for
    expect(wrapper.findAll('.product-card')).toHaveLength(3)
  })

  it('displays heading with title', () => {
    const wrapper = mount(ProductGrid, {
      props:  { title: 'Electronics', products: mockProducts },
      global: { plugins: [createTestingPinia()] },
    })
    expect(wrapper.find('h2').text()).toContain('Electronics')
  })

  it('shows empty state when products is empty', () => {
    const wrapper = mount(ProductGrid, {
      props:  { title: 'Empty', products: [] },
      global: { plugins: [createTestingPinia()] },
    })
    expect(wrapper.find('.empty-state').exists()).toBe(true)
    expect(wrapper.text()).toContain('ไม่พบสินค้า')
    expect(wrapper.findAll('.product-card')).toHaveLength(0)
  })

  it('shows skeleton when loading=true', () => {
    const wrapper = mount(ProductGrid, {
      props:  { title: '', products: [], loading: true },
      global: { plugins: [createTestingPinia()] },
    })
    expect(wrapper.find('.product-card--skeleton').exists()).toBe(true)
  })

  it('filters products by search query', async () => {
    const wrapper = mount(ProductGrid, {
      props:  { title: '', products: mockProducts },
      global: { plugins: [createTestingPinia()] },
    })
    // พิมพ์ค้นหา
    await wrapper.find('input').setValue('Item A')
    // ต้องเหลือแค่ 1 card
    expect(wrapper.findAll('.product-card')).toHaveLength(1)
  })

  it('calls cart.add when add-to-cart is emitted from ProductCard', async () => {
    const pinia = createTestingPinia({ createSpy: vi.fn })
    const wrapper = mount(ProductGrid, {
      props:  { title: '', products: mockProducts },
      global: { plugins: [pinia] },
    })
    // simulate emit from child ProductCard
    await wrapper.findComponent({ name: 'ProductCard' }).vm.$emit('add-to-cart', 1)
    // cart.add ควรถูกเรียก
    const { useCartStore } = await import('@/stores/cart')
    expect(useCartStore().add).toHaveBeenCalledWith(1)
  })
})

    { id: 1, name: 'Blue Shirt', price: 399, inStock: true, rating: 4, reviewCount: 10, primaryImage: '' },
  ],
}

describe('CategoryPage', () => {
  let router: ReturnType<typeof createRouter>

  beforeEach(() => {
    // สร้าง router จำลอง
    router = createRouter({
      history: createMemoryHistory(),
      routes:  [{ path: '/category/:slug', component: CategoryPage }],
    })
    // mock fetch
    global.fetch = vi.fn().mockResolvedValue({
      ok:   true,
      json: () => Promise.resolve(mockCategory),
    })
  })

  afterEach(() => vi.restoreAllMocks())

  it('shows products after fetch resolves', async () => {
    await router.push('/category/shirts')
    const wrapper = mount(CategoryPage, {
      global: {
        plugins: [router, createTestingPinia()],
      },
    })

    // รอ async fetch + DOM update
    await flushPromises()

    expect(wrapper.text()).toContain('เสื้อผ้า')
    expect(wrapper.text()).toContain('Blue Shirt')
  })

  it('shows skeleton (ProductGrid loading) while fetching', async () => {
    // fetch ที่ไม่ resolve ทันที
    global.fetch = vi.fn().mockReturnValue(new Promise(() => {}))
    await router.push('/category/shirts')

    const wrapper = mount(CategoryPage, {
      global: { plugins: [router, createTestingPinia()] },
    })

    expect(wrapper.find('.product-card--skeleton').exists()).toBe(true)
  })

  it('re-fetches when route slug changes', async () => {
    await router.push('/category/shirts')
    mount(CategoryPage, {
      global: { plugins: [router, createTestingPinia()] },
    })
    await flushPromises()

    await router.push('/category/shoes')
    await flushPromises()

    // fetch ต้องถูกเรียก 2 ครั้ง (shirts + shoes)
    expect(global.fetch).toHaveBeenCalledTimes(2)
  })
})
