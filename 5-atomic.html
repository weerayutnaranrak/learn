Atomic Design

UI System design methodology by Brad Frost — build components from smallest to largest, like a chemist building matter from atomsmethodology ออกแบบ UI Systems โดย Brad Frost — สร้าง components จากเล็กไปใหญ่ เหมือนนักเคมีสร้างสสารจากอะตอม

💡 What is Atomic Design?Atomic Design คืออะไร?
By Brad Frost — "We're not designing pages, we're designing systems of components"แนวคิดโดย Brad Frost — "We're not designing pages, we're designing systems of components"

This methodology views the Interface like matter in nature — composed of small pieces (Atoms) that combine into increasingly complex things, making Design Systems consistent, reusable, and easy to maintainแนวคิดนี้มองว่า Interface เหมือนสสารในธรรมชาติ — ประกอบขึ้นจาก ชิ้นส่วนเล็กๆ (Atoms) ที่รวมกันเป็นสิ่งที่ซับซ้อนขึ้นเรื่อยๆ ทำให้ Design System สอดคล้อง, ซ้ำใช้ได้, และ Maintain ง่าย

📄 PagesPages — หน้า

Template + Real Content = What the user actually seesTemplate + Real Content = สิ่งที่ผู้ใช้เห็นจริงๆ

Pages are:Pages คือ:

• Templates with real data insertedTemplate ที่ใส่ real data เข้าไปแล้ว
• What the end-user actually seesสิ่งที่ end-user เห็นจริงๆ
• Tests whether the Design System works with real contentทดสอบว่า Design System ทำงานร่วมกับ real content ได้
• "Evidence" that templates actually workเป็น "evidence" ว่า templates ใช้งานได้จริง

Important:สำคัญ:
Pages should have no new styling — every component comes from the previous levelsหน้า Pages ไม่ควรมี styling ใหม่ — ทุก component ใช้จาก levels ที่ผ่านมา

<script setup lang="ts">
type Variant = 'primary' | 'secondary' | 'ghost' | 'danger'
type Size    = 'sm' | 'md' | 'lg'

const props = defineProps<{
  variant?: Variant
  size?:    Size
  disabled?: boolean
  icon?:    string
}>()

const emit = defineEmits<{
  click: [event: MouseEvent]
}>()
</script>

<template>
  <button
    :class="['btn', `btn--${variant ?? 'primary'}`, `btn--${size ?? 'md'}`]"
    :disabled="disabled"
    @click="emit('click', $event)"
  >
    <span v-if="icon" class="btn__icon">{{ icon }}</span>
    <slot />
  </button>
</template>

<script setup lang="ts">
import AppButton from '@/components/atoms/AppButton.vue'
import AppBadge  from '@/components/atoms/AppBadge.vue'

export interface Product {
  id:            number
  name:          string
  price:         number
  originalPrice?: number
  discountPct?:  number
  rating:        number
  reviewCount:   number
  primaryImage:  string
  inStock:       boolean
  isNew?:        boolean
}

const props = defineProps<{ product: Product }>()
const emit  = defineEmits<{ 'add-to-cart': [id: number] }>()

const formattedPrice = computed(() =>
  props.product.price.toLocaleString('th-TH')
)
</script>

<template>
  <article class="product-card">
    <RouterLink :to="`/products/${product.id}`" class="product-card__image-link">
      <img :src="product.primaryImage" :alt="product.name" loading="lazy" />
      <AppBadge v-if="product.isNew" color="blue">ใหม่</AppBadge>
      <AppBadge v-if="product.discountPct" color="red">-{{ product.discountPct }}%</AppBadge>
    </RouterLink>

    <div class="product-card__body">
      <h3 class="product-card__name">{{ product.name }}</h3>

      <div class="product-card__rating">
        ⭐ {{ product.rating }} ({{ product.reviewCount }})
      </div>

      <div class="product-card__price">
        <span class="price-current">฿{{ formattedPrice }}</span>
        <span v-if="product.originalPrice" class="price-original">
          ฿{{ product.originalPrice.toLocaleString('th-TH') }}
        </span>
      </div>

      <AppButton v-if="product.inStock" icon="🛒" size="sm"
        @click="emit('add-to-cart', product.id)">
        เพิ่มในตะกร้า

<script setup lang="ts">
import ProductCard, { type Product } from '@/components/molecules/ProductCard.vue'
import { useCartStore } from '@/stores/cart'

const props = defineProps<{
  title:      string
  products:   Product[]
  loading?:   boolean
}>()

const cart        = useCartStore()
const searchQuery = ref('')

const filtered = computed(() =>
  props.products.filter(p =>
    p.name.toLowerCase().includes(searchQuery.value.toLowerCase())
  )
)
</script>

<template>
  <section class="product-grid-section">
    <div class="product-grid__header">
      <h2>{{ title }} ({{ filtered.length }})</h2>
      <input v-model="searchQuery" placeholder="ค้นหาสินค้า..." class="search-input" />
    </div>

    <!-- Loading skeleton -->
    <div v-if="loading" class="product-grid">
      <div v-for="n in 6" :key="n" class="product-card product-card--skeleton" />
    </div>

    <!-- Product list -->
    <div v-else-if="filtered.length" class="product-grid">
      <ProductCard
        v-for="product in filtered"
        :key="product.id"
        :product="product"
        @add-to-cart="cart.add($event)"
      />
    </div>

    <!-- Empty state -->
    <div v-else class="empty-state">
      <span class="empty-state__icon">📭</span>
      <p>ไม่พบสินค้าที่ตรงกับ "{{ searchQuery }}"</p>
    </div>
  </section>
</template>

Props & Emits (data flow)
• Props → pass data down (parent → child)ส่งข้อมูลลง (parent → child)
• Emits → send event up (child → parent)ส่ง event ขึ้น (child → parent)
• v-model = props + emit combinedprops + emit รวมกัน
Composables (logic reuse)
• Replaces Mixins from Vue 2แทน Mixins ของ Vue 2

atoms/AppButton.spec.ts Atom · Unit Test 
import { mount } from '@vue/test-utils'
import AppButton from '@/components/atoms/AppButton.vue'

describe('AppButton', () => {
  it.each([
    ['primary',   'btn--primary'],
    ['secondary', 'btn--secondary'],
    ['danger',    'btn--danger'],
  ])('variant="%s" adds class "%s"', (variant, expectedClass) => {
    const wrapper = mount(AppButton, { props: { variant } })
    expect(wrapper.classes()).toContain(expectedClass)
  })

  it('renders slot content', () => {
    const wrapper = mount(AppButton, { slots: { default: 'Buy Now' } })
    expect(wrapper.text()).toContain('Buy Now')
  })

  it('renders icon when icon prop is passed', () => {
    const wrapper = mount(AppButton, { props: { icon: '🛒' } })
    expect(wrapper.find('.btn__icon').text()).toBe('🛒')
  })

  it('emits click event when clicked', async () => {
    const wrapper = mount(AppButton)
    await wrapper.trigger('click')
    expect(wrapper.emitted('click')).toHaveLength(1)
  })

  it('does not emit when disabled', async () => {
    const wrapper = mount(AppButton, { props: { disabled: true } })
    await wrapper.trigger('click')
    // disabled attribute blocks native click → no custom emit
    expect(wrapper.emitted('click')).toBeUndefined()
  })

  it('applies correct size class', () => {
    const wrapper = mount(AppButton, { props: { size: 'lg' } })
    expect(wrapper.classes()).toContain('btn--lg')
  })
})

import { mount } from '@vue/test-utils'
import ProductCard from '@/components/molecules/ProductCard.vue'

const baseProduct = {
  id: 1, name: 'Go T-Shirt', price: 299,
  primaryImage: '/img/tshirt.jpg', rating: 4,
  reviewCount: 120, inStock: true, isNew: false,
}

describe('ProductCard', () => {
  it('renders product name and price', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.text()).toContain('Go T-Shirt')
    expect(wrapper.text()).toContain('299')
  })

  it('shows "ใหม่" badge when isNew=true', () => {
    const wrapper = mount(ProductCard, {
      props: { product: { ...baseProduct, isNew: true } },
    })
    expect(wrapper.text()).toContain('ใหม่')
  })

  it('hides "ใหม่" badge when isNew=false', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.text()).not.toContain('ใหม่')
  })

  it('shows add-to-cart button when inStock=true', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.find('button').exists()).toBe(true)
    expect(wrapper.text()).toContain('เพิ่มในตะกร้า')
  })

  it('shows "หมดสต็อก" badge when inStock=false', () => {
    const wrapper = mount(ProductCard, {
      props: { product: { ...baseProduct, inStock: false } },
    })
    expect(wrapper.find('button').exists()).toBe(false)
    expect(wrapper.text()).toContain('หมดสต็อก')
  })

  it('emits add-to-cart with product id when button clicked', async () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    await wrapper.find('button').trigger('click')
    expect(wrapper.emitted('add-to-cart')?.[0]).toEqual([1])
  })

  // Snapshot — เปรียบเทียบ HTML ทั้ง component
  it('matches snapshot', () => {
    const wrapper = mount(ProductCard, { props: { product: baseProduct } })
    expect(wrapper.html()).toMatchSnapshot()
    // ครั้งแรก: สร้าง __snapshots__/ProductCard.spec.ts.snap
    // เปลี่ยน template: รัน vitest --update-snapshots
  })
})

🏷️ data-testid with Atomic Designdata-testid กับ Atomic Design
Stable selectors that scale with your component hierarchySelector ที่เสถียรและขยายตามลำดับชั้น Component
Why data-testid?ทำไมต้องใช้ data-testid?

CSS classes and DOM structure change often. data-testid is a stable, intention-revealing hook that keeps tests green through refactors. Atomic Design's hierarchy gives a natural naming scheme.CSS class และโครงสร้าง DOM เปลี่ยนบ่อย data-testid คือ hook ที่เสถียรและบอกเจตนาชัดเจน ทำให้ test ผ่านแม้จะ refactor และลำดับชั้นของ Atomic Design ก็ให้รูปแบบการตั้งชื่อที่เป็นธรรมชาติ

import { render, screen } from '@testing-library/vue'
import userEvent from '@testing-library/user-event'
import ProductCard from '@/components/molecules/ProductCard.vue'

const product = { id: 1, name: 'Sneaker X', price: 1990, inStock: true, isNew: true }

describe('ProductCard testid', () => {
  it('exposes scoped test-ids for all key elements', () => {
    render(ProductCard, {
      props: { product, testId: 'molecule-product-card' }
    })

    expect(screen.getByTestId('molecule-product-card')).toBeTruthy()
    expect(screen.getByTestId('molecule-product-card-name').textContent)
      .toContain('Sneaker X')
    expect(screen.getByTestId('molecule-product-card-price').textContent)
      .toContain('1,990')
    expect(screen.getByTestId('molecule-product-card-add-btn')).toBeTruthy()
  })

  it('emits add-to-cart when add button is clicked', async () => {
    const { emitted } = render(ProductCard, {
      props: { product, testId: 'molecule-product-card' }
    })

    await userEvent.click(screen.getByTestId('molecule-product-card-add-btn'))
    expect(emitted()['add-to-cart']).toEqual([[1]])
  })
})
3 Rules for good test-ids3 กฎสำหรับ test-id ที่ดี
  • Uniqueไม่ซ้ำ — add an index suffix (-0, -1) when rendering lists so selectors stay unambiguousเพิ่ม index suffix (-0, -1) เมื่อ render เป็น list เพื่อไม่ให้ selector ซ้ำกัน
  • Stableเสถียร — never derive from text content or CSS classes that can change during refactoringอย่าดึงมาจากข้อความหรือ CSS class ที่อาจเปลี่ยนตอน refactor
  • Descriptiveบอกเจตนา — name the role, not the tag — -add-btn over -button-2ตั้งชื่อตาม หน้าที่ ไม่ใช่ tag เช่น -add-btn ไม่ใช่ -button-2
