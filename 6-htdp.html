HTDP

How to Design Programs — วิธีคิดเกี่ยวกับการเขียนโปรแกรมอย่างเป็นระบบ ด้วย Design Recipe 6 ขั้นตอน ก่อน code ทุกครั้ง

💡 HTDP คืออะไร?
หนังสือและ methodology โดย Matthias Felleisen et al. — "ออกแบบก่อน code"

HTDP สอนว่าการเขียนโปรแกรมที่ดีต้องเริ่มจาก การคิดและออกแบบ ก่อนเสมอ ไม่ใช่นั่ง code ทันที — ด้วย Design Recipe ที่เป็น step-by-step process ทำให้โค้ดอ่านง่าย ทดสอบได้ และ correct มากขึ้น

Core Philosophy: "A good program is not just code that works — it's code that communicates its intent clearly."

โปรแกรมที่ดีไม่ใช่แค่ทำงานได้ — แต่ต้องสื่อสาร intent ของตัวเองได้ชัดเจน
ปัญหาที่ HTDP แก้

นักพัฒนา code ก่อนคิด

เขียน code ทันที → ไม่รู้ว่าจะ handle ข้อมูลอะไร → แก้ bug ไม่หมด → code ยุ่งเหยิง

วิธีแก้

Design Recipe 6 ขั้นตอน

กำหนด Data → กำหนด Signature → เขียน Purpose → สร้าง Examples → Template → เขียน Body → Test

📐 Design Recipe — 6 ขั้นตอน
ทำตามทุกครั้งก่อนเขียน function — ไม่ข้ามขั้นตอน
1

📊 Data Definition — กำหนดข้อมูล

ก่อนอื่น — คิดว่า data ที่ function รับและคืนคืออะไร? กำหนด type ให้ชัดเจน บอกว่าข้อมูลแต่ละชนิดหมายความว่าอะไร มีข้อจำกัดอะไรบ้าง

ตัวอย่าง: ระบบคะแนนนักเรียน

Grade คือคะแนน: เป็น int ในช่วง 0–100
LetterGrade คือเกรด: หนึ่งใน "A", "B", "C", "D", "F"
Student คือนักเรียน: มี Name (string) และ Score (Grade)

ข้อจำกัด: Grade ต้องไม่ติดลบ, ไม่เกิน 100

2

✍️ Signature + Purpose — ลายเซ็นและจุดประสงค์

เขียน Function Signature (input types → output type) และ Purpose Statement ในบรรทัดเดียวว่า "function นี้ทำอะไร?" ห้ามบอก HOW — บอกแค่ WHAT

ตัวอย่าง

// scoreToGrade รับคะแนน 0-100 คืน letter grade (A/B/C/D/F)
func scoreToGrade(score int) string

// averageScore คำนวณคะแนนเฉลี่ยของนักเรียนในกลุ่ม
func averageScore(students []Student) float64

3

📝 Examples — ตัวอย่าง Input/Output

ก่อน code! เขียน ตัวอย่างที่คาดหวัง ว่า function จะทำงานอย่างไร ครอบคลุม normal cases, edge cases, และ boundary conditions

ตัวอย่าง (เขียนเป็น test cases ก่อนเลย)

Input Output เหตุผล
score = 90 → "A"
score = 80 → "B"
score = 50 → "F"
score = 0 → "F" edge: ต่ำสุด
score = 100 → "A" edge: สูงสุด
4

🏗️ Template — โครงสร้าง

เขียน skeleton ของ function ตามโครงสร้างของ data ถ้า input เป็น if/else condition → template มี if/else ถ้า input เป็น list → template มี loop

Template สำหรับ scoreToGrade (input เป็น range → ใช้ if-else chain)

func scoreToGrade(score int) string {
  if score >= ... {
    return "..."
  } else if score >= ... {
    return "..."
  } else {
    return "..."
  }
}

5

💻 Body — เขียน Code จริง

ตอนนี้แหละถึงเวลา code! ใส่ logic เข้าไปใน template ที่เตรียมไว้ เพราะเรามี signature, examples และ template แล้ว — code ตรงนี้จะ ง่ายมาก

6

✅ Tests — ทดสอบจาก Examples

นำ examples จากขั้นตอนที่ 3 มาเป็น test cases ถ้าทำตาม Design Recipe ตั้งแต่ต้น — tests ส่วนใหญ่ผ่านได้ทันที เพราะเราคิด examples ก่อน code แล้ว

💻 ตัวอย่างที่ 1 — Grade System (ง่าย)
ใช้ Design Recipe ทั้ง 6 ขั้นตอน
grade/grade.go — ครบทุกขั้นตอน Go 
package grade

import "fmt"

// ═══════════════════════════════════════════════════════════════════════════
// STEP 1: DATA DEFINITION
// ═══════════════════════════════════════════════════════════════════════════

// Grade คือคะแนนสอบ: เป็น int ในช่วง [0, 100]
// Invariant: 0 <= Grade <= 100
type Grade int

// LetterGrade คือเกรดตัวอักษร: หนึ่งใน "A", "B", "C", "D", "F"
type LetterGrade string

const (
    LetterA LetterGrade = "A" // 80-100
    LetterB LetterGrade = "B" // 70-79
    LetterC LetterGrade = "C" // 60-69
    LetterD LetterGrade = "D" // 50-59
    LetterF LetterGrade = "F" // 0-49
)

// Student คือนักเรียนที่มีชื่อและคะแนน
type Student struct {
    Name  string
    Score Grade
}

// ═══════════════════════════════════════════════════════════════════════════
// STEP 2: SIGNATURE + PURPOSE
// ═══════════════════════════════════════════════════════════════════════════

// ToLetterGrade รับคะแนน 0-100 คืน letter grade ตามเกณฑ์:
// A=80+, B=70-79, C=60-69, D=50-59, F=0-49
func (g Grade) ToLetterGrade() (LetterGrade, error) {

    // ═══════════════════════════════════════════════════════════════════════
    // STEP 3: EXAMPLES (documented ไว้เป็น reference)
    // g=90  → LetterA (in A range)
    // g=80  → LetterA (boundary: ต่ำสุดของ A)
    // g=79  → LetterB (boundary: สูงสุดของ B)
    // g=0   → LetterF (ต่ำสุด)
    // g=100 → LetterA (สูงสุด)
    // g=-1  → error (ออกนอกช่วง)
    // g=101 → error (ออกนอกช่วง)
    // ═══════════════════════════════════════════════════════════════════════

    // ═══════════════════════════════════════════════════════════════════════
    // STEP 4: TEMPLATE — input เป็น range ของตัวเลข → if-else chain
    // ═══════════════════════════════════════════════════════════════════════

    // ═══════════════════════════════════════════════════════════════════════
    // STEP 5: BODY
    // ═══════════════════════════════════════════════════════════════════════
    if g < 0 || g > 100 {
        return "", fmt.Errorf("invalid grade %d: must be 0-100", g)
    }

    switch {
    case g >= 80:
        return LetterA, nil
    case g >= 70:
        return LetterB, nil
    case g >= 60:
        return LetterC, nil
    case g >= 50:
        return LetterD, nil
    default:
        return LetterF, nil
    }
}

// ─────────────────────────────────────────────────────────────────────────
// STEP 2: SIGNATURE + PURPOSE (function ที่ 2)
// averageGrade คำนวณคะแนนเฉลี่ยของนักเรียนทั้งหมดในกลุ่ม
// คืน 0 ถ้ากลุ่มว่าง
func averageGrade(students []Student) float64 {

    // STEP 3: EXAMPLES
    // []                          → 0.0        (empty → 0)
    // [{A,90}]                    → 90.0       (single)
    // [{A,90},{B,80}]             → 85.0       (two students)
    // [{A,100},{B,0},{C,50}]      → 50.0       (three students)

    // STEP 4: TEMPLATE — input เป็น list → ใช้ loop
    // if empty → return 0
    // else → sum all → divide by count

    // STEP 5: BODY
    if len(students) == 0 {
        return 0
    }
    var sum int
    for _, s := range students {
        sum += int(s.Score)
    }
    return float64(sum) / float64(len(students))
}

// topStudents คืนนักเรียนที่ได้เกรด A ทั้งหมด (เรียงตามคะแนนสูงสุด)
// คืน empty slice ถ้าไม่มีใครได้ A
func topStudents(students []Student) []Student {
    // STEP 3: EXAMPLES
    // []                          → []
    // [{A,70}]                    → [] (ไม่ได้ A)
    // [{A,90},{B,85}]             → [{A,90}]
    // [{A,90},{B,85},{C,82}]      → [{A,90},{B,82}] (เรียงตาม score)

    // STEP 4: TEMPLATE — input เป็น list → filter + sort

    // STEP 5: BODY
    var result []Student
    for _, s := range students {
        grade, err := s.Score.ToLetterGrade()
        if err == nil && grade == LetterA {
            result = append(result, s)
        }
    }
    // Sort by score descending
    for i := 0; i < len(result)-1; i++ {
        for j := i + 1; j < len(result); j++ {
            if result[j].Score > result[i].Score {
                result[i], result[j] = result[j], result[i]
            }
        }
    }
    return result
}

func TestToLetterGrade(t *testing.T) {
    tests := []struct {
        name  string
        input grade.Grade
        want  grade.LetterGrade
        err   bool
    }{
        // Normal cases
        {"A range",      90,  grade.LetterA, false},
        {"B range",      75,  grade.LetterB, false},
        {"C range",      65,  grade.LetterC, false},
        {"D range",      55,  grade.LetterD, false},
        {"F range",      45,  grade.LetterF, false},
        // Boundaries — ขอบเขตสำคัญมาก!
        {"A lower bound", 80, grade.LetterA, false},
        {"B upper bound", 79, grade.LetterB, false},
        {"B lower bound", 70, grade.LetterB, false},
        {"zero",           0, grade.LetterF, false},
        {"max",          100, grade.LetterA, false},
        // Edge cases — ข้อมูลไม่ valid
        {"negative",     -1,  "",            true},
        {"over 100",    101,  "",            true},
    }

    for _, tc := range tests {
        t.Run(tc.name, func(t *testing.T) {
            got, err := tc.input.ToLetterGrade()
            if tc.err {
                if err == nil {
                    t.Errorf("expected error for input %d", tc.input)
                }
                return
            }
            if err != nil {
                t.Fatalf("unexpected error: %v", err)
            }
            if got != tc.want {
                t.Errorf("ToLetterGrade(%d) = %q, want %q", tc.input, got, tc.want)
            }
        })
    }
}

💻 ตัวอย่างที่ 2 — ระบบ Shopping Cart (ซับซ้อนขึ้น)
HTDP กับ Recursive Data Structures และ Complex Business Rules
cart/cart.go — Design Recipe กับ Complex Data Go 
package cart

import (
    "errors"
    "fmt"
)

// ═══════════════════════════════════════════════════════════════════════════
// STEP 1: DATA DEFINITION
// ═══════════════════════════════════════════════════════════════════════════

// Price คือราคาเป็นสตางค์ (หน่วย: satang): เป็น int64 >= 0
type Price int64

func (p Price) Baht() float64 { return float64(p) / 100 }
func (p Price) String() string { return fmt.Sprintf("฿%.2f", p.Baht()) }

// Quantity คือจำนวนสินค้า: เป็น int > 0
type Quantity int

// CartItem คือรายการสินค้าใน cart:
// ProductID ต้องไม่ว่าง
// UnitPrice >= 0
// Qty > 0
type CartItem struct {
    ProductID string
    Name      string
    UnitPrice Price
    Qty       Quantity
}

// Subtotal คือยอดรวมของ item นี้
func (i CartItem) Subtotal() Price { return Price(int64(i.UnitPrice) * int64(i.Qty)) }

// Cart คือตะกร้าสินค้า:
// Items เป็น slice — อาจว่างก็ได้
// แต่ละ ProductID ต้องไม่ซ้ำกัน
type Cart struct {
    ID    string
    Items []CartItem
}

// ─────────────────────────────────────────────────────────────────────────
// STEP 2: SIGNATURE + PURPOSE
// AddItem เพิ่มสินค้าลงใน cart
// ถ้า ProductID เดิมมีอยู่แล้ว ให้เพิ่ม Qty แทน
// ถ้า item ไม่ valid คืน error
func (c *Cart) AddItem(item CartItem) error {

    // STEP 3: EXAMPLES
    // (empty cart) + {P1, "ข้าว", 3000, 1} → [{P1, "ข้าว", 3000, 1}]
    // [{P1, "ข้าว", 3000, 1}] + {P1, "ข้าว", 3000, 2} → [{P1, "ข้าว", 3000, 3}] (merge)
    // [] + {P1, "", 3000, 1} → error (name ว่าง)
    // [] + {P1, "ข้าว", -100, 1} → error (ราคาติดลบ)
    // [] + {P1, "ข้าว", 3000, 0} → error (qty ไม่บวก)

    // STEP 4: TEMPLATE — validate → find existing → add/merge

    // STEP 5: BODY
    if item.ProductID == "" {
        return errors.New("product ID required")
    }
    if item.Name == "" {
        return errors.New("product name required")
    }
    if item.UnitPrice < 0 {
        return errors.New("price must be non-negative")
    }
    if item.Qty <= 0 {
        return errors.New("quantity must be positive")
    }

    // ถ้ามีอยู่แล้ว ให้รวม quantity
    for i, existing := range c.Items {
        if existing.ProductID == item.ProductID {
            c.Items[i].Qty += item.Qty
            return nil
        }
    }
    // เพิ่มใหม่
    c.Items = append(c.Items, item)
    return nil
}

// ─────────────────────────────────────────────────────────────────────────
// STEP 2: SIGNATURE + PURPOSE
// RemoveItem ลบสินค้าออกจาก cart ด้วย ProductID
// ถ้าไม่พบ ProductID คืน error
func (c *Cart) RemoveItem(productID string) error {
    // STEP 3: EXAMPLES
    // [{P1}, {P2}] remove P1 → [{P2}]
    // [{P1}]       remove P1 → []
    // [{P1}]       remove P2 → error (ไม่พบ)
    // []            remove P1 → error (cart ว่าง)

    // STEP 4: TEMPLATE — ค้นหา index → ลบ (filter out)

    // STEP 5: BODY
    for i, item := range c.Items {
        if item.ProductID == productID {
            c.Items = append(c.Items[:i], c.Items[i+1:]...)
            return nil
        }
    }
    return fmt.Errorf("product %s not found in cart", productID)
}

// ─────────────────────────────────────────────────────────────────────────
// STEP 2: SIGNATURE + PURPOSE
// Total คำนวณยอดรวมทั้ง cart ก่อนส่วนลด
// คืน 0 ถ้า cart ว่าง
func (c *Cart) Total() Price {
    // STEP 3: EXAMPLES
    // []                         → 0
    // [{P1, 3000, 1}]            → 3000
    // [{P1, 3000, 2}]            → 6000
    // [{P1, 3000, 1}, {P2, 2000, 3}] → 9000

    // STEP 4: TEMPLATE — list → fold/reduce (sum)

    // STEP 5: BODY
    var total Price
    for _, item := range c.Items {
        total += item.Subtotal()
    }
    return total
}

// ─────────────────────────────────────────────────────────────────────────
// STEP 2: SIGNATURE + PURPOSE
// ApplyDiscount คิดราคาหลังส่วนลด pct (0-100%)
// ถ้า pct ไม่อยู่ในช่วง [0,100] คืน error
func (c *Cart) ApplyDiscount(pct int) (Price, error) {
    // STEP 3: EXAMPLES
    // total=10000, pct=0    → 10000  (ไม่ลด)
    // total=10000, pct=10   → 9000   (ลด 10%)
    // total=10000, pct=100  → 0      (ฟรี)
    // total=10000, pct=-1   → error
    // total=10000, pct=101  → error
    // total=0,     pct=50   → 0      (cart ว่าง)

    // STEP 4: TEMPLATE — validate pct → compute

    // STEP 5: BODY
    if pct < 0 || pct > 100 {
        return 0, fmt.Errorf("discount %d%% out of range [0,100]", pct)
    }
    total := c.Total()
    discount := Price(int64(total) * int64(pct) / 100)
    return total - discount, nil
}

package cart_test

import (
    "testing"
    "myapp/cart"
)

func makeItem(id, name string, price int64, qty int) cart.CartItem {
    return cart.CartItem{
        ProductID: id, Name: name,
        UnitPrice: cart.Price(price),
        Qty:       cart.Quantity(qty),
    }
}

// Tests สำหรับ AddItem
func TestCart_AddItem(t *testing.T) {
    t.Run("add new item", func(t *testing.T) {
        c := &cart.Cart{}
        if err := c.AddItem(makeItem("P1", "ข้าว", 3000, 1)); err != nil {
            t.Fatal(err)
        }
        if len(c.Items) != 1 {
            t.Errorf("expected 1 item, got %d", len(c.Items))
        }
    })

    t.Run("add duplicate merges qty", func(t *testing.T) {
        c := &cart.Cart{}
        c.AddItem(makeItem("P1", "ข้าว", 3000, 1))
        c.AddItem(makeItem("P1", "ข้าว", 3000, 2))
        if len(c.Items) != 1 {
            t.Errorf("expected 1 item (merged), got %d", len(c.Items))
        }
        if c.Items[0].Qty != 3 {
            t.Errorf("expected qty 3, got %d", c.Items[0].Qty)
        }
    })

    t.Run("reject empty name", func(t *testing.T) {
        c := &cart.Cart{}
        if err := c.AddItem(makeItem("P1", "", 3000, 1)); err == nil {
            t.Error("expected error for empty name")
        }
    })

    t.Run("reject zero quantity", func(t *testing.T) {
        c := &cart.Cart{}
        if err := c.AddItem(makeItem("P1", "ข้าว", 3000, 0)); err == nil {
            t.Error("expected error for zero qty")
        }
    })
}

// Tests สำหรับ Total
func TestCart_Total(t *testing.T) {
    t.Run("empty cart", func(t *testing.T) {
        c := &cart.Cart{}
        if got := c.Total(); got != 0 {
            t.Errorf("empty cart total = %v, want 0", got)
        }
    })

    t.Run("single item", func(t *testing.T) {
        c := &cart.Cart{}
        c.AddItem(makeItem("P1", "ข้าว", 3000, 2)) // 3000 * 2 = 6000
        if got := c.Total(); got != 6000 {
            t.Errorf("total = %v, want 6000", got)
        }
    })

    t.Run("multiple items", func(t *testing.T) {
        c := &cart.Cart{}
        c.AddItem(makeItem("P1", "ข้าว", 3000, 1))  // 3000
        c.AddItem(makeItem("P2", "น้ำ", 2000, 3))   // 6000
        if got := c.Total(); got != 9000 {           // 9000
            t.Errorf("total = %v, want 9000", got)
        }
    })
}

// Tests สำหรับ ApplyDiscount
func TestCart_ApplyDiscount(t *testing.T) {
    tests := []struct {
        name    string
        total   int64
        pct     int
        want    int64
        wantErr bool
    }{
        {"no discount",   10000, 0,    10000, false},
        {"10% off",       10000, 10,   9000,  false},
        {"50% off",       10000, 50,   5000,  false},
        {"100% off",      10000, 100,  0,     false},
        {"empty cart",    0,     50,   0,     false},
        {"negative pct",  10000, -1,   0,     true},
        {"over 100 pct",  10000, 101,  0,     true},
    }
    for _, tc := range tests {
        t.Run(tc.name, func(t *testing.T) {
            c := &cart.Cart{}
            if tc.total > 0 {
                c.AddItem(makeItem("P1", "สินค้า", tc.total, 1))
            }
            got, err := c.ApplyDiscount(tc.pct)
            if tc.wantErr {
                if err == nil { t.Error("expected error") }
                return
            }
            if err != nil { t.Fatalf("unexpected error: %v", err) }
            if int64(got) != tc.want {
                t.Errorf("ApplyDiscount(%d%%) = %d, want %d", tc.pct, got, tc.want)
            }
        })
    }
}
🎯 Key Principles ของ HTDP
หลักที่ 1

Think Before Code

ใช้เวลา 80% คิด 20% code — ทำให้ bug ในขั้น coding น้อยลงมาก เพราะคิดครบแล้ว

หลักที่ 2

Examples First

เขียน examples ก่อน code เสมอ — examples บังคับให้คิดถึง edge cases ที่อาจลืม

หลักที่ 3

Data Drives Design

Shape ของ code ควรสะท้อน shape ของ data — data เป็น list → code ใช้ loop, data เป็น tree → code ใช้ recursion

หลักที่ 4

Small, Composable Functions

แต่ละ function ทำสิ่งเดียว (Single Responsibility) ทดสอบได้ง่าย และ compose ต่อกันเป็น complex logic ได้

หลักที่ 5

Explicit Contracts

Signature และ Purpose Statement เป็น "สัญญา" ของ function — ผู้เรียกรู้ว่าจะได้อะไร, ต้องส่งอะไร

หลักที่ 6

Tests as Specification

Tests ไม่ใช่แค่ "ทดสอบ" — มันคือ specification ของ behavior ที่ชัดเจนที่สุด readable โดยทีม

HTDP + TDD: HTDP Design Recipe เข้ากันได้ดีมากกับ TDD (Test Driven Development) เพราะทั้งคู่สอนให้ เขียน test ก่อน code — examples ในขั้นที่ 3 ของ HTDP คือ failing test ที่ต้องทำให้ผ่าน
สรุป Design Recipe:
1. Data → กำหนด types ที่ชัดเจน
2. Signature → บอก input/output types
3. Examples → ตัวอย่าง expected behavior
4. Template → skeleton ตาม data structure
5. Body → เขียน code จริง
6. Tests → verify ด้วย examples จากข้อ 3
